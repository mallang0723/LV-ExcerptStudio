## 사용법

1. 메시지의 동작 줄에서 **❝ 발췌**를 누릅니다. 전체 메시지 본문이 스튜디오에 들어갑니다. 폰에서도 메시지를 꾹 누를 필요가 없습니다.
2. 미리보기 아래의 **발췌할 범위**에서 문장 또는 문단을 고릅니다. **선택 해제** 후 원하는 항목을 누르고 **선택 범위 적용**을 누르면 드래그 없이 발췌할 수 있습니다. **본문 전체 복원**으로 처음 본문을 다시 가져옵니다.
3. PC에서는 메시지 본문을 드래그한 뒤 뜨는 **❝ 발췌**도 사용할 수 있습니다. 미리보기에서 드래그한 뒤 **드래그한 부분만 남기기**로 더 줄일 수 있습니다.
4. 원작의 형광펜·밑줄·검열·치환 규칙·대사 색·작품 정보·배경·카드 설정으로 꾸밉니다. 마크는 미리보기에서 글자를 드래그하고 색을 눌러 적용합니다. **발췌 범위를 바꾸면 마크가 초기화**되므로 범위를 먼저 정하세요.
5. **PNG 저장**을 누릅니다. `발췌_YYYYMMDD_HHMMSS.png`로 브라우저 다운로드에 저장됩니다. 원작처럼 카드 설정 폭의 두 배 해상도로 그립니다.
6. 닫기 버튼, 폰 오른쪽 위의 **X**, **Esc**, 브라우저 뒤로가기로 닫습니다.

폰에서는 미리보기와 설정이 위아래로 놓입니다. 스튜디오 본문을 스크롤하면 모든 설정을 사용할 수 있으며, 닫기와 저장 버튼은 별도 영역에 남습니다. 호스트의 꾹 누르기/우클릭 메뉴는 그대로 사용할 수 있습니다.

## 원작과 달라진 점

- Spindle 식별자 `excerpt_studio_lv`, 버전 `1.0.0-lv.1-v2`. **프런트엔드만 사용하고 요청 권한은 없습니다.** 서버 워커·모델·임베딩을 사용하지 않습니다.
- 기본 작가가 **LUMIVERSE**, 작품명은 현재 채팅방 이름입니다. 수정한 작품명은 방별, 작가는 기기 전체에 기억합니다.
- 메시지 동작 줄 진입 및 문장/문단 탭 선택을 추가했습니다. 드래그는 같은 메시지 본문 안에서만 허용합니다. 이름·동작 버튼·편집창·확장 위젯은 발췌에서 제외합니다.
- 스튜디오 UI는 루미버스 기본·사용자 테마 변수에 맞춥니다. 카드 자체의 종이/색/이미지는 선택한 출력 설정을 따릅니다.
- 글자 크기 최소값을 15px로 올리고 작품명·작가도 최소 15px로 출력합니다. 터치 대상은 44px 이상이며 폰에서는 전체 화면을 사용합니다.
- 폰트 목록은 현재 페이지에 등록된 FontFace입니다. 리디바탕은 선택 시 원작의 CDN 로딩을 사용하며 실패하면 명조 계열로 대체됩니다.
- 설정은 이 확장 전용 `excerpt-studio-lv-prefs-v1` localStorage에 저장합니다. 저장소가 막혀도 작업할 수 있지만 설정은 유지되지 않습니다. 이미지 파일은 다음 실행에 보관하지 않습니다.
- 원작의 이모지 토큰 분할 문제와 이전 창의 비동기 제목 응답이 새 창에 반영될 수 있는 문제에 적용 횟수를 검사하는 빌드 패치를 넣었습니다. 원본 파일은 그대로입니다.

발췌·편집·PNG 생성은 브라우저 안에서 처리합니다. 채팅방 제목은 호스트의 읽기 전용 API로 가져오고, 리디바탕을 선택하면 폰트 CDN에 요청합니다. 메시지나 이미지 파일을 업로드하지 않습니다. HTTP에서도 UUID·클립보드·파일 선택 저장 API에 의존하지 않고 Blob과 `<a download>`로 저장합니다.

## 설치

Lumiverse의 Spindle에서 이 GitHub 저장소 주소로 설치하세요. `spindle.json`과 빌드된 `dist/frontend.js`가 포함되어 있어 별도 빌드 없이 설치할 수 있습니다.

## 개발 및 검증

Node와 Bun이 있는 환경에서:

```sh
npm run verify
npm run build
npm test
```

Bun 실행 경로를 따로 지정하려면 `BUN_BIN=/path/to/bun npm run build`를 사용합니다. 빌드는 고정 SHA-256과 모든 패치 횟수를 검사한 뒤 번들 하나를 만듭니다. 런타임 npm 의존성은 없습니다. 테스트는 Node 26에서 확인했으며 `--test-isolation=none`을 지원하는 Node가 필요합니다.

DOM/브라우저 검수 도구는 선택 사항입니다. 도구가 필요하면 별도로 설치합니다:

```sh
npm install --no-save --package-lock=false jsdom@29.1.1 playwright@1.58.2
npm run test:dom
npx playwright install firefox chromium
npm run qa
npm run test:visibility
```

이미 설치된 도구를 읽어서 쓸 때는 `JSDOM_MODULE`, `PLAYWRIGHT_MODULE`, `FIREFOX_BIN`, `CHROMIUM_BIN`으로 절대 경로를 지정할 수 있습니다. `QA_BROWSERS=firefox npm run qa`는 Firefox만 실행합니다. 브라우저 하네스는 HTTPS/HTTP fixture를 요청 라우팅으로 제공하며 실제 호스트나 로컬 서버에 접속하지 않습니다. 결과와 스크린샷은 `qa/results/`에 저장됩니다.

## 검증 결과와 확인하지 못한 것

검증 도구에는 원작 알고리즘 단위 테스트, 실제 번들의 DOM 통합 테스트, Firefox 360·390·1280 / HTTP·HTTPS / 라이트·다크 / minimal·bubble 검수가 포함됩니다.

- Chromium은 이 실행 환경의 소켓 제한으로 시작하지 못했습니다. 실제 Android/iOS 앱 WebView, 브라우저 다운로드 저장 위치 및 노치/키보드가 있는 기기의 동작은 미확인입니다.
- 사용자 테마 전체, 리디바탕 CDN 실연결/CORS, 기기 이미지의 모든 형식은 별도 검수가 필요합니다.
- 이전 호스트나 API 오류로 방 이름을 못 얻으면 작품명 칸에 직접 입력할 수 있습니다.
- 문장 분리는 Intl.Segmenter를 사용하며 미지원 환경에서는 문장부호 기준으로 나눕니다. 치환한 단어 일부만 드래그하여 자르면 원문 대응 때문에 해당 단어 전체가 남을 수 있습니다.
- 좁은 미리보기는 화면 폭에 맞춰 줄바꿈합니다. PNG는 설정한 카드 폭으로 그리므로 줄바꿈이 다를 수 있습니다. 매우 긴 본문은 기기별 캔버스 크기/메모리 한계가 있습니다.
